# Völker Tiefbau – Website

Responsive Website für Völker Tiefbau aus Gladbeck. Die statische Seite verwendet HTML, CSS und JavaScript sowie GSAP für Animationen.

## Lokal starten

Im Projektordner `python3 -m http.server 8000` ausführen und `http://localhost:8000` im Browser öffnen.

## Veröffentlichung

Die Website ist für GitHub Pages aus dem Root-Verzeichnis des `main`-Branches vorbereitet. Das Bewerbungsformular erstellt eine E-Mail im lokalen E-Mail-Programm; es speichert keine Bewerbungen auf einem Server.

Unternehmensinformationen und Baustellenbilder stammen von der bestehenden Website von Völker Tiefbau. Das Logo wurde für den Entwurf bereitgestellt.
